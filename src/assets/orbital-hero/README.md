# Логотипы на орбитах

- `mts-mark-white.svg`: белая монограмма МТС из существующего
  `src/assets/figma/header/logo-mts-ads.svg`; исходные контуры сохранены.

- `vk-ads.svg`: оригинальный знак из SVG шапки https://ads.vk.com/.
  Отделён от текстовой части, геометрия и фирменные цвета сохранены.
- `telegram.svg`: `Logo.svg` из официального набора
  https://telegram.org/tour/screenshots.
- `avito.svg`: цветной знак из https://commons.wikimedia.org/wiki/File:Avito_logo.svg
  (автор: Авито; источник оригинала: https://start.avito.ru).
  Отделён от надписи, геометрия и цвета сохранены.

Все файлы локальные; внешние запросы при показе сцены не нужны.
