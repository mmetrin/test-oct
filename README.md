# МТС Ads — test-oct

Исходники сайта на React и Vite. Главная страница: `index.html`; дополнительные макеты находятся в соседних папках.

## Локальный запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

## Орбитальное хиро

Отдельная страница: `/test-oct/orbital-hero/`. Использует существующие шапку,
шрифты МТС, цветовые переменные и текст хиро. 3D-сцена загружается только на
этой странице; геометрия и студийное окружение создаются программно, без
внешних моделей или HDRI.

Параметры находятся в `src/features/orbital-hero/orbitalConfig.js`: камера,
ограничение pixel ratio, амплитуда параллакса, радиусы и наклоны орбит,
скорости, размеры и цвета модулей. Чтобы добавить модуль, добавьте запись
в `modules` с уникальным `id` и `orbit`, соответствующим идентификатору орбиты.
Углы и скорости заданы в радианах и радианах в секунду.
Для брендированного модуля задайте `brand`: `vk`, `telegram` или `avito`.
Логотипы находятся на крупных объёмных плашках, развёрнутых к камере.
`cornerOffset` смещает плашку относительно её орбиты. Маска центра и прямых
краёв плашки оставляет пересечения линий только возле четырёх уголков,
поэтому сами знаки остаются открытыми во время движения и параллакса.
Источники локальных SVG указаны в `src/assets/orbital-hero/README.md`.
Палитра глянцевых градиентных орбит задана в `orbitGradient.js`, а `gradientOffset`
в конфигурации сдвигает цветовой переход каждой орбиты. В центре — цельная
красная сфера со знаком МТС, спроецированным на её поверхность.

Кнопка внизу хиро останавливает анимацию. При `prefers-reduced-motion` сцена
статична; при скрытии вкладки или уходе блока за экран постоянный рендеринг
останавливается. На мобильных устройствах композиция располагается под текстом.

## Публикация

При пуше в `main` GitHub Actions собирает сайт с базовым путём `/test-oct/` и публикует `dist` на GitHub Pages. Команда `npm run build:pages` добавляет экран ввода пароля ко всем HTML-страницам.

Парольный экран — только визуальный барьер. GitHub Pages не предоставляет для этого сайта настоящую серверную авторизацию: файлы публичного репозитория и ресурсы сайта доступны напрямую.
