# МТС Ads — test-oct

Исходники сайта на React и Vite. Главная страница: `index.html`; дополнительные макеты находятся в соседних папках.

## Локальный запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

## Публикация

При пуше в `main` GitHub Actions собирает сайт с базовым путём `/test-oct/` и публикует `dist` на GitHub Pages. Команда `npm run build:pages` добавляет экран ввода пароля ко всем HTML-страницам.

Парольный экран — только визуальный барьер. GitHub Pages не предоставляет для этого сайта настоящую серверную авторизацию: файлы публичного репозитория и ресурсы сайта доступны напрямую.
